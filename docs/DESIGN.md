# 设计记录

## 目标

重启 DSH 时先见到她，再进入工作。不是「播放一段片头」，而是一块**可停留、可交互、
可跳过**的启动页。

## 参考：Detroit: Become Human 的主菜单

Quantic Dream 官方复盘 [How Chloe Became Human](https://blog.quanticdream.com/how-chloe-became-human/)
里，编剧兼导演 David Cage 的原话：

> 我们知道能读到主机的时钟，所以知道连接时的日期和时间……于是我们开始写文本，
> 覆盖有人在圣诞节、跨年夜、法国国庆日、美国独立日启动游戏的情况。一件事接着一件，
> 我们把菜单做得更复杂，让它能根据**星期几**、**距上次连接多久**、以及**我们在游戏里
> 做了什么**来反应——就好像它也知道我们的选择。
>
> 我们通过**乘以剧本的入口点**、根据条件和变量，创造了一种模拟某种「意识」的行为。
> 为此我们录了非常多的台词。

这句话定下了本项目的技术路线：**不做 LLM 生成，用「条件 × 台词」制造记忆感。**

### 拆出来的六条原理

| 原理 | Chloe 怎么做 | 本插件怎么落 |
|---|---|---|
| ① 她看着你 | 特写镜头，视线直视镜头；手工动画主要做在眼睛上 | ⏳ 需要分层素材（瞳孔层） |
| ② 她记得你 | 读时钟、读距上次连接、读游戏进度 | ✅ 离线时长 / 时段 / 来访次数 |
| ③ 她有分寸 | 13 个问题，每个只问三次，没人答就不再问 | ✅ 台词按离线时长收敛 |
| ④ 她有自己的节奏 | 停在菜单她会主动开口 | ✅ 打字机自动播放 |
| ⑤ 她有不完美 | 微动作、呼吸、视线移开 | ⏳ 呼吸已可做，眨眼待素材 |
| ⑥ 她有一个结局 | 最后可以放她走或抹掉记忆 | ❌ 不做（这是应用启动页，不是游戏） |

## 三个已拍板的决定

### 1. 用宿主注入，不用 client slot

自带加载卡片是前端 JS 在 React 挂载后创建的原生 DOM（`[data-dsh-boot]` /
`[data-dsh-boot-spinner]`）。client 侧插件在它之后才有机会。

宿主提供 `webserver/index-inject` 事件与 `webServer.tapIndex()`，其行由服务端渲染进
HTML 正文，必然先于卡片绘制。本项目只用前者，因为结构化行是 JSON 可序列化的，
未来静态部署也兼容。

### 2. 只覆盖，不隐藏

社区里有插件用 `[data-dsh-boot]:has(...){display:none}` 把自带卡片藏掉。但那个选择器
指向的是 **DSH 私有实现细节**，不是公开契约；上游一改，所有这么做的插件同时失效，
表现为**永久黑屏**。

所以本项目：覆盖层 z-index 顶到 `2147483000`，不碰 `#root`，不藏卡片。
最坏情况退化成「多看一眼加载卡片」。

### 3. 台词不用 LLM

| | 脚本分支 | 实时 LLM |
|---|---|---|
| 首字延迟 | 0 | 1–3 秒（正好在最尴尬的时候） |
| 离线可用 | ✅ | ❌ |
| 可控性 | ✅ 可审 | ❌ |
| 成本 | 0 | 每次启动一次调用 |
| 像人吗 | ✅ 这才是 Chloe 的做法 | ⚠️ 反而容易「AI 味」 |

留了一个后门：将来可以做「想多聊两句」的入口，那一段才走模型。

## 待定

- **立绘分层**：见 [ART.md](ART.md)。这是「她在看着你」的唯一门槛。
- **语音**：预生成 vs 运行时合成。倾向预生成（零延迟、离线、音色稳定），
  但需要先定音色与台词量。
- **进入时机**：目前是「说完解锁按钮」。备选是「按启动耗时决定说几句」——
  DSH 加载慢就多说两句，快就只说一句，让等待刚好被填满。

## 状态机

```
页面请求
   ↓
Host 读 state.json → 算 deltaMs / visits / hour → 选台词
   ↓
注入 5 行（global / style / html / watchdog / script）
   ↓
首帧绘制（此时加载卡片尚未创建）
   ↓
脚本：打字机逐句播放 → 说完解锁按钮
   ↓
点击按钮 或 Esc  →  淡出 520ms → 移除节点
   ↓
（兜底：主脚本未初始化时，watchdog 20s 后强制移除）
```

## 版本要求

不声明 `engines.dsh`：只依赖 `webserver/index-inject` 这一个事件与 Node 内置模块。
将来若该事件改名，需要同步更新 `lib/index.js` 与本文档。
