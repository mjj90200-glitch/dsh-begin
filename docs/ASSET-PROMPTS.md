# 出图规格（给 Img3.0 用）

> 目标：拿到一套**能在本地做差分抠层**的素材，让启动页 support 呼吸、眨眼、口型。

---

## 先说结论：不要生成「分层图」

图像模型画分层是不可靠的——它会**重新构图**，你以为在画「眼睛层」，它给你一张新的全身图。

所以正确做法是：

> **生成同一张图的不同状态**，我来做抠层。

具体说：先用参考图出一张满意的全身立绘（`base`），之后**全部用「图生图 / 局部重绘(inpaint) / 编辑」模式**，输入就是这张 `base`，每次只改一个地方（闭眼、张嘴、瞳孔移动）。

这样每张变体除了目标区域外，其他像素几乎完全一致，我就能用**像素差分**精确切出眼睑层和嘴部层。

---

## 通用规格（所有图都必须一致）

| 项 | 要求 |
|---|---|
| 画布 | **1024 × 1536**（2:3 竖版），所有图完全相同 |
| 格式 | PNG |
| 背景 | **纯色 `#FF00FF`（品红）**，平涂，无渐变无阴影 |
| 构图 | 全身完整入画，人物居中，头顶/鞋底各留 6% 空白 |
| 视角 | 正面、平视、同一姿势，**不允许**缩放或裁切 |

**为什么是品红**：她的主色是蓝、白、深藏青，品红在色相上离得很远，色键抠图不会伤到裙子、围裙和鲸尾。

**如果模型能直接导出透明背景**，那就用透明 PNG，更好——请先检查一下导出的图是真透明（棋盘格）还是白底。

## ① 主立绘 `base.png`

**输入**：把参考图（你上传的那张）作为图像参考 / 风格参考。

**提示词**（直接复制）：

```
以参考图中的角色为准，重绘一张全身正面立绘，画布 1024×1536（2:3）。

角色：蓝色长卷发少女，发长及腰，头顶有一根翘起的呆毛；两侧为深蓝色鲸鱼鳍状耳；身后一条蓝灰色渐变鲸鱼尾。深藏青色连衣裙，白色围裙（围裙右下角有一枚小鲸鱼刺绣），奶油色蝴蝶结领结，袖口与裙摆各有一枚小蝴蝶结；白色过膝袜，深色玛丽珍鞋。

姿态：正面站立，身体正对镜头，一手轻提裙摆，另一手抬到肩膀高度做打招呼的手势；面带微笑，嘴微张。

画风：日系赛璐璐厚涂，冷色调，柔和过渡光，干净线稿，低噪点，不要颗粒滤镜。

构图：全身完整入画，从头顶到鞋底都在画面内；人物水平居中；头顶与鞋底各留约 6% 空白。

背景：纯色 #FF00FF 品红，完全平涂；不要阴影、不要渐变、不要地面、不要光晕、不要道具、不要文字、不要水印、不要边框。

禁止：改变发色、瞳色、服装配色或任何配饰；添加武器或道具；侧身或背面视角；俯视或仰视；裁掉头顶或脚部；任何背景元素。
```

> ⚠️ 这一步**值得多抽几次卡**。后面所有变体都建立在它上面，base 不合适就全部作废。

---

## ② 变体（都基于 `base` 做局部重绘）

以下每条都是**独立操作**：输入永远是 `base.png`，不是上一张变体。

### `eyes-closed.png` — 闭眼（最高优先级）

```
保持输入图像的一切完全不变，只把角色的双眼改为自然闭合：上下眼睑合拢，睫毛自然下垂，眉毛和脸颊保持不变。除眼睛区域外，其余像素不得有任何变化——不要改变构图、光照、颜色、位置和大小。
```

### `eyes-half.png` — 半闭眼（次要）

```
保持输入图像的一切完全不变，只把角色的上眼睑下垂到瞳孔上方约一半，呈半睁的困倦状态，虹膜仍然可见。其余部分不得有任何变化。
```

### `mouth-open.png` — 口型 · 微张

```
保持输入图像的一切完全不变，只把角色的嘴部改为微微张开的小口型，看不到牙齿和舌头，脸颊与下巴保持原样。其余部分不得有任何变化。
```

### `mouth-round.png` — 口型 · 圆口

```
保持输入图像的一切完全不变，只把角色的嘴部改为略呈圆形的「う」口型，嘴唇轻轻聚拢。其余部分不得有任何变化。
```

### `gaze-left.png` / `gaze-right.png` — 目光偏移（可选）

```
保持输入图像的一切完全不变，只把左右眼的瞳孔一起向画面左侧平移一点点（约瞳孔直径的三分之一），虹膜保持正圆，眼白与眼睑不变，头部不要转动。其余部分不得有任何变化。
```

（`gaze-right` 把「左侧」改成「右侧」）

---

## ③ 生成顺序与一致性守则

1. **只做 base**，反复抽卡到满意 —— 这是最贵也最值的一步
2. **锁定 base**：记下 seed（如果平台支持），之后所有变体都用它
3. 后续**一律用图生图 / 局部重绘 / 编辑**，输入 = `base.png`
4. **每次只改一个变量**，只框选目标区域（眼睛或嘴），框选范围留一点边
5. 如果模型擅自缩放、裁切、重构图 → 那张作废，重来
6. 导出保持 1024×1536 PNG，不要压缩

---

## ④ 交付清单

```
base.png
eyes-closed.png
eyes-half.png          （可选）
mouth-open.png
mouth-round.png
gaze-left.png          （可选）
gaze-right.png         （可选）
```

优先级：**base > eyes-closed > mouth > gaze**。
只有 `base` 也能做（整图微动 ≈ 70% 观感）；有 `base + eyes-closed` 就能眨眼，观感会明显不一样。

---

## ⑤ 拿到之后我会做什么

1. **色键**：把 `#FF00FF` 变成透明（并检查边缘有没有品红残留）
2. **差分抠层**：
   - `eyes-closed` 减 `base` → 差异区域 = 眼睛 → 得到眼睑替换层
   - `mouth-*` 之间求差 → 嘴部层
   - `gaze-*` 之间求差 → 虹膜位移范围
3. **掩膜处理**：对差分掩膜做收缩 + 羽化，去掉噪点和压缩边缘
4. **组装**：分层 PNG + 我在 `lib/splash.js` 里写的定点变换（呼吸、眨眼定时器、口型帧、瞳孔跟随鼠标）
5. **验收**：在 `preview/splash-preview.html` 里逐项对比开关

## ⑦ 如果某一步一直做不成

| 卡在哪 | 退化方案 | 观感 |
|---|---|---|
| 变体全部守不住 | 只用 `base`，整图微动 + 语音 | ~70% |
| 只有闭眼能守 | 呼吸 + 眨眼 + 语音 | ~85% |
| 口型守不住 | 说话时只做轻微上下浮动 + 字幕节奏 | ~80% |
| 模型透明背景可用 | 跳过色键，直接用透明 PNG | 更好 |

告诉我卡在哪一步，我按对应方案改代码。
